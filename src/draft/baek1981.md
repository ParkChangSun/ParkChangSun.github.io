# Baekjoon 1981 - 배열에서 이동

이번 문제는 배울 점이 많았다.

## 문제

$N \times N$ 의 정수 배열에서 $(1,1) \to (N,N)$ 경로의 최댓값과 최솟값의 차이의 최소

입력

- $2 \leq N \leq 100$
- `matrix` $0 \leq v \leq 200$

## 풀이

가장 간단한 풀이는 
1 모든 경로를 탐색한다.
2 모든 경로들 중 최솟값을 찾는다.

나는 그냥 여기서부터 막혔다. 모든 경로를 다 뒤져서 최솟값을 찾아내는 것 밖에는 생각이 나지 않았다. 가지고 있는 값도 없어서 생각을 발전시킬 수가 없었다.

딱 봐도 모든 경로를 탐색하는 것은 불가능하다. 그러면 어떤 경로를 탐색해야 하는가?

문제 풀이에 사용할 수 있는 값은 직접 구할 수 없는 값인 경로의 최댓값과 최솟값 밖에 없다.

발상의 전환을 해서 구해야 하는 최솟값으로 탐색 범위를 좁힐 수 있다.

구해야 하는 값이 경로의 최댓값-경로의 최솟값이므로 이 두 값을 먼저 정해 놓고 탐색을 시작한다. 최솟값~최댓값 범위 내의 값들로 경로를 완성할 수 있다면 
1 어떤 경로가 가질 수 있는 최댓값과 최솟값을 정한다.
2 가능한 경로가 있는지 탐색한다.

배열 내의 값의 범위인 0~200 부터 시작한다. 정답 코드들을 좀 살펴보니 방법이 두 가지로 나뉘었다.

1 high값을 이분 탐색으로 좁히면서 i=0~mid i~mid 범위의 경로를 탐색한다. 경로가 가능하면 이분 탐색한다.
2 0~0 부터 시작해서 경로가 가능하면 low++, 불가능하면 high++

2 방법이 코드도 깔끔하고 더 빨랐다.

## 배운 점

문제를 접근할 때 먼저 브루트 포스로 단순하게 시작해야 한다. 그래야 문제 풀이의 핵심 논리들을 이끌어낼 수 있다. 이 문제에서는 구할 수는 없지만 정해놓고 범위를 좁힐 수 있는 최소~최대 값 범위가 있었다. 지금 당장 구할 수 없는 값이라도 범위를 정해 놓고 풀이에 활용하는 방법을 배웠다.

## 코드

map이 좀 느린 편이다. 처음에는 visited를 `map[Point]struct{}`를 사용했었다.

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"slices"
)

var std = bufio.NewReadWriter(bufio.NewReader(os.Stdin), bufio.NewWriter(os.Stdout))

var n int
var matrix [][]int

type Point struct {
	i, j int
}

func main() {
	defer std.Flush()

	fmt.Fscan(std, &n)
	matrix = make([][]int, n)
	numberSet := []int{}
	for i := range matrix {
		matrix[i] = make([]int, n)
		for j := range matrix[i] {
			fmt.Fscan(std, &matrix[i][j])
			numberSet = append(numberSet, matrix[i][j])
		}
	}

	slices.Sort(numberSet)
	numberSet = slices.Compact(numberSet)

	res := 200

	lowIndex, highIndex := 0, 0

	for lowIndex <= highIndex && highIndex < len(numberSet) {
		if search(numberSet[lowIndex], numberSet[highIndex]) {
			res = min(res, numberSet[highIndex]-numberSet[lowIndex])
			lowIndex++
		} else {
			highIndex++
		}
	}

	fmt.Fprint(std, res)
}

var neighborSet = []Point{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}

func search(minBound, maxBound int) bool {
	if x := matrix[0][0]; x < minBound || maxBound < x {
		return false
	}

	visited := make([][]bool, n)
	for i := range visited {
		visited[i] = make([]bool, n)
	}

	queue := []Point{{0, 0}}
	visited[0][0] = true

	for len(queue) > 0 {
		cur := queue[0]
		queue = queue[1:]

		if cur.i == n-1 && cur.j == n-1 {
			return true
		}

		for _, v := range neighborSet {
			ni, nj := cur.i+v.i, cur.j+v.j

			if ni < 0 || ni >= n || nj < 0 || nj >= n || visited[ni][nj] || matrix[ni][nj] < minBound || maxBound < matrix[ni][nj] {
				continue
			}

			queue = append(queue, Point{ni, nj})
			visited[ni][nj] = true
		}
	}

	return false
}
```
