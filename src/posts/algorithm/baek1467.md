# Beakjoon 1467 - 수 지우기

# 입력

- $N \leq 1000$ 자리 자연수 `number`
- $N$ 개 이하의 숫자들 `targets`
- `number` 와 `targets` 에 0은 없는 것으로 보인다.

# 문제

`number` 에서 `targets` 의 숫자들을 지웠을 때 가장 큰 수 구하기

# 풀이

그리디 알고리즘은 한 단계의 최적의 선택이 전체의 최적의 선택으로 이어진다.

처음에는 `targets`를 순회하면서 `numbers`에서 수를 지웠을 때 커지면 ok인 방식으로 풀었다. `numbers[i]<numbers[i+1]` 일 때 지우는 것이다. 뒤의 큰 수를 하나 끌어오는 느낌이다. 이러면 지금 단계에서 최댓값이니까 전체의 최댓값으로 이어지겠지?

내가 생각한 최적 구조는 수를 하나 지웠을 때 최대가 결과의 최대이다 였다.

질문 게시판에서 반례를 찾아보고 나서야 이 방식이 틀렸다는 것을 깨달았다. i+1이 작은수라서 넘겼는데 뒤에 더 큰 수가 있을 수도 있다.

원점으로 돌아가서 다시 생각해야 했다. 지우는 방법은 많지만, 수의 배치만 다를 뿐 수의 개수는 같다. 그럼 원래 순서에 맞게 남은 수들을 배열해서 최댓값을 만들 수 있을 것이다.

배열할 수의 개수를 추적하는 `reduced` 맵을 사용했다.
큰 수가 되도록 배열하려면 앞에서부터 가장 큰 수를 골라야 한다. 단순히 앞에서부터 수를 하나하나 보는 방식은 이미 실패했으니 9부터 시작해서 큰 수를 찾아보자. 이 수와 이 뒤의 수들로 정답을 완성할 수 있어야 한다. 즉 이 수 앞의 수들은 그냥 지워지는 것이다.
[index:] 배열의 수들을 세어서 `reduced`의 개수만큼 있는지 확인한다. 부족하다면 이 수는 선택할 수 없다.
선택한 수는 `res`에 붙인다. `reduced`에 있는 모든 수를 사용할 때까지 반복한다.

정답 코드들을 좀 찾아보니까 스택을 이용하는 풀이가 정석처럼 쓰이고 있었다. `res` 스택에 수들을 차례로 넣다가 큰 수가 나오면 뺄 수 있는 만큼 빼는 방식이다. 내가 생각했던 뒤의 큰 수를 앞으로 당기는 느낌이다. 나는 뒤의 수들의 개수가 충분한가로 순서를 판별했다면 이 방식은 스택을 사용해 더 효율적으로 순서를 판별했다.

이 문제의 최적 구조는 숫자를 추가할 때 앞의 작은 수들을 지우면 최대의 순서이다 이다.

# 코드

```go
package main

import (
	"bufio"
	"fmt"
	"maps"
	"os"
	"slices"
)

var std = bufio.NewReadWriter(bufio.NewReader(os.Stdin), bufio.NewWriter(os.Stdout))

func main() {
	defer std.Flush()

	var numbers, targets []byte
	fmt.Fscan(std, &numbers, &targets)

	reduced := map[byte]int{}
	for _, v := range numbers {
		reduced[v]++
	}
	for _, v := range targets {
		reduced[v]--
		if reduced[v] == 0 {
			delete(reduced, v)
		}
	}

	res := []byte{}

	for len(reduced) > 0 {
		for i := byte('9'); i > byte('0'); i-- {
			if _, o := reduced[i]; !o {
				continue
			}
			targetIndex := slices.Index(numbers, i)

			contains := true
			temp := maps.Clone(reduced)
			for _, v := range numbers[targetIndex:] {
				temp[v]--
			}
			for _, v := range temp {
				if v > 0 {
					contains = false
					break
				}
			}
			if !contains {
				continue
			}

			res = append(res, i)
			numbers = numbers[targetIndex+1:]
			reduced[i]--
			if reduced[i] == 0 {
				delete(reduced, i)
			}
			break
		}
	}

	fmt.Fprint(std, string(res))
}
```
